# アイデア帳

知人限定で、考え中のビジネスアイデアとその「思考の過程」を共有するための小さなWebアプリです。

## コンセプト

- 完成した綺麗なアイデアだけでなく、そこに至るまでの試行錯誤を残すことを目的にしています。
- テキストの削除機能はありません。考えを訂正するときは、元の文章に**取り消し線**を引いて残したまま、新しい文章を書き足します。過去の思考の痕跡がそのまま履歴として積み上がっていきます。
- 個別アカウント登録は不要です。共有リンクと合言葉(パスワード)を知っている人だけが、表示名を名乗って参加できます。

## 使い方(ローカルで試す)

```bash
npm install
npm run dev
```

`http://localhost:3000` を開くと合言葉の入力画面が出ます。初期設定の合言葉は `.env` の `APP_PASSWORD` です(下記参照)。

## 設定 (`.env`)

```
APP_PASSWORD="idea2026"          # 知人に共有する合言葉。配る前に変更してください
SESSION_SECRET="..."             # ログインセッションの署名用シークレット。公開前に必ずランダムな値に変更してください
```

## データの保存先

SQLiteファイル(`better-sqlite3`)にすべてのアイデア・思考ログ・コメントを保存します。デフォルトでは `data/dev.db` に作成されます(`.gitignore` 済み)。保存場所を変えたい場合は `.env` の `DATABASE_PATH` を設定してください。

## 知人と共有するには(デプロイ)

このアプリは今のところローカル環境用に作られています。実際に知人に共有リンクを配るには、どこかのホスティングサービスにデプロイする必要があります。

おすすめは **Railway**(このアプリのようにファイルベースのSQLiteを永続化しやすく、Webアプリのデプロイも簡単です)。他に Render や Fly.io でも動きます。

デプロイ時にやること:

1. `APP_PASSWORD` と `SESSION_SECRET` を必ず推測されにくい値に変更する
2. SQLiteデータを永続化するボリューム(ディスク)をマウントし、`DATABASE_PATH` をそこに向ける
3. デプロイ後に発行されたURL + 合言葉を知人に共有する

デプロイ作業は次回、接続先のホスティングサービス(Railway等)をCoworkに接続してから改めて進められます。

## 技術構成

- Next.js 14 (App Router) + TypeScript + Tailwind CSS
- better-sqlite3 によるシンプルなデータ保存(ORM不使用)
- 合言葉 + 表示名による軽量セッション認証(Web Crypto APIで署名したCookie)
